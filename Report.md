In the project folder an implementation of a MPC (multi party computation) scheme using TLS to send messages between clients. The implementation is written in Go (language is built for this sorta stuff) using the base crypto TLS and Random number packages. 

TLS should ensure secure communication between clients so that data does not leak to eavesdroppers and ensures data has not been tampered with. Aka we get confidentiality and integrity. The integrity is ensured by using signatures to make sure that the proper parties are communicating and confidentiality is done through the encryption of the data that is to be sent thus only the parties that have the proper keys can decrypt it. (IMPORTANT I DID NOT IMPLEMENT TLS INSTEAD THE GOLANG PACKAGE IS USED ONE SHOULD NEVER TRY AND IMPLEMENT THAT STUFF THEMSELVES)
MPC is vital for confidentiality as we restrict data access through the use of the share sharing scheme. Patient don't learn the whole secret and thus cannot learn anything important and is thus a restricted user in the network.

To explain the process step by step we first initialize all the patients (Clients) and make them connect to each other. We give each client a secret and the ports of all other clients to be dialed. Once all clients are connected through a secure TLS connection we can then listen to its own port, if the hospital sends "go" to the clients the client will start sharing the shares. A client has a list of shares the first index being its own and the next n indices being dedicated to a specific client. We of course do a computation with the secrets before sharing by summing our secret with the one that is dedicated to them thus we get an aggregated result. Once all clients have shared with eachother they send the result to the hospital where the result should be the same for all final messages shared with it.

### Adversary model attacks
In our case if the adversary behaves according to our rules and protocols then the best they can learn is aggregated share results from other clients and never all shares thusly we do not leak any secret information to them which is great! The attacker thusly powerless. This would be a passive adversary model.
